# ЧАСТЬ 1. ПОДРОБНАЯ ТЕОРИЯ

### 1. Постановка задачи
Дано линейное дифференциальное уравнение второго порядка:
$$y''(x) + a(x)y(x) = b(x)$$

Требуется найти $2\pi$-периодическое решение на отрезке $[a, b] = [0, 2\pi]$.
Периодичность функции и её производной означает, что на концах отрезка выполняются два краевых условия:
1. $y(a) = y(b)$ (значения функции совпадают);
2. $y'(a) = y'(b)$ (значения первых производных совпадают).

---

### 2. Принцип суперпозиции для линейных уравнений
Из курса дифференциальных уравнений известно фундаментальное свойство: общее решение линейного неоднородного уравнения представляется как сумма линейной комбинации решений однородного уравнения и одного частного решения неоднородного уравнения:
$$y(x) = C_1 y_1(x) + C_2 y_2(x) + y_{\text{неодн}}(x)$$

где:
* $y_1(x)$ и $y_2(x)$ — два линейно независимых решения соответствующего однородного уравнения:
  $$y'' + a(x)y = 0$$
* $y_{\text{неодн}}(x)$ — любое частное решение исходного неоднородного уравнения:
  $$y'' + a(x)y = b(x)$$
* $C_1, C_2$ — константы, которые определяются из граничных (краевых) условий.

---

### 3. Разностная схема 
Непрерывный отрезок $[a, b]$ разбивается на $N$ равных отрезков. 
* Шаг сетки (как обозначено на доске):
  $$d = \frac{b - a}{N} = \frac{2\pi}{N}$$
* Узлы сетки:
  $$x_i = a + i \cdot d, \quad i = 0, 1, 2, \dots, N$$
* Значение функции в узле $x_i$ обозначается как $y_i = y(x_i)$.

Вторую производную в узле $x_i$ аппроксимируют центральной разностью второго порядка точности (формула с доски на фото 2):
$$y''(x_i) \approx \frac{y_{i+1} - 2y_i + y_{i-1}}{d^2}$$

Подставим эту разность в уравнение $y''(x_i) + a(x_i)y_i = b(x_i)$:
$$\frac{y_{i+1} - 2y_i + y_{i-1}}{d^2} + a(x_i)y_i = b(x_i)$$

Умножим всё уравнение на $d^2$:
$$y_{i+1} - 2y_i + y_{i-1} + d^2 a(x_i) y_i = d^2 b(x_i)$$

Выразим значение в следующем узле $y_{i+1}$ через два предыдущих ($y_i$ и $y_{i-1}$):
$$y_{i+1} = 2y_i - y_{i-1} + d^2 \big(b(x_i) - a(x_i)y_i\big)$$

Это явная шаговая рекуррентная формула: зная значения в двух соседних узлах $y_{i-1}$ и $y_i$, можно однозначно вычислить значение в следующем узле $y_{i+1}$.

---

### 4. Почему этот метод работает за время $O(N)$ 
Вместо того чтобы строить гигантскую матрицу размера $5000 \times 5000$ и обращать её, задача решается последовательным «шаганием» слева направо (метод Коши).

Чтобы запустить рекурсию, нам нужны два стартовых значения: $y_0$ и $y_1$.
На доске (фото 3) преподаватель выписал три независимых прогона:

1. **Первое однородное решение** ($b(x) = 0$):
   * Начальные условия: $y_0 = 0$, $y_1 = d$.
   * Рекуррентная формула:
     $$y_{i+1}^{(1)} = 2y_i^{(1)} - y_{i-1}^{(1)} - d^2 a(x_i) y_i^{(1)}$$
   * Результат: массив $\{y_i^{(1)}\}_{i=0}^N$.

2. **Второе однородное решение** ($b(x) = 0$):
   * Начальные условия: $y_0 = d$, $y_1 = 0$.
   * Рекуррентная формула:
     $$y_{i+1}^{(2)} = 2y_i^{(2)} - y_{i-1}^{(2)} - d^2 a(x_i) y_i^{(2)}$$
   * Результат: массив $\{y_i^{(2)}\}_{i=0}^N$.

3. **Частное неоднородное решение** (с правой частью $b(x)$):
   * Начальные условия: $y_0 = 0$, $y_1 = d$.
   * Рекуррентная формула:
     $$y_{i+1}^{(\text{неод})} = 2y_i^{(\text{неод})} - y_{i-1}^{(\text{неод})} + d^2 \big(b(x_i) - a(x_i)y_i^{(\text{неод})}\big)$$
   * Результат: массив $\{y_i^{(\text{неод})}\}_{i=0}^N$.

Каждый прогон делается за один цикл от $1$ до $N-1$, то есть требует всего $N$ операций.

---

### 5. Определение констант $C_1$ и $C_2$ из краевых условий
Итоговое решение во всех узлах есть сумма:
$$y_i = C_1 y_i^{(1)} + C_2 y_i^{(2)} + y_i^{(\text{неод})}$$

Подставим это выражение в условия периодичности:

#### Условие 1: $y(a) = y(b) \implies y_0 = y_N$
$$C_1 y_0^{(1)} + C_2 y_0^{(2)} + y_0^{(\text{неод})} = C_1 y_N^{(1)} + C_2 y_N^{(2)} + y_N^{(\text{неод})}$$

Переносим слагаемые с $C_1, C_2$ влево, а свободные члены вправо:
$$C_1 \big(y_0^{(1)} - y_N^{(1)}\big) + C_2 \big(y_0^{(2)} - y_N^{(2)}\big) = y_N^{(\text{неод})} - y_0^{(\text{неод})}$$

#### Условие 2: $y'(a) = y'(b) \implies y'(0) = y'(2\pi)$
Производную на концах сетки аппроксимируют односторонней разностью:
* В начале ($x = 0$): $y'(0) \approx \frac{y_1 - y_0}{d}$
* В конце ($x = 2\pi$): $y'(2\pi) \approx \frac{y_N - y_{N-1}}{d}$

Условие $y'(0) = y'(2\pi)$ примет вид:
$$\frac{y_1 - y_0}{d} = \frac{y_N - y_{N-1}}{d} \iff y_1 - y_0 = y_N - y_{N-1}$$

Подставляя суперпозицию:
$$C_1 \left(\frac{y_1^{(1)} - y_0^{(1)}}{d} - \frac{y_N^{(1)} - y_{N-1}^{(1)}}{d}\right) + C_2 \left(\frac{y_1^{(2)} - y_0^{(2)}}{d} - \frac{y_N^{(2)} - y_{N-1}^{(2)}}{d}\right) = \frac{y_N^{(\text{неод})} - y_{N-1}^{(\text{неод})}}{d} - \frac{y_1^{(\text{неод})} - y_0^{(\text{неод})}}{d}$$

#### Решение системы $2 \times 2$ методом Крамера
Получили систему:
$$\begin{cases}
M_{11} C_1 + M_{12} C_2 = B_1 \\
M_{21} C_1 + M_{22} C_2 = B_2
\end{cases}$$
Определитель матрицы:
$$\det = M_{11} M_{22} - M_{12} M_{21}$$
По правилу Крамера:
$$C_1 = \frac{B_1 M_{22} - M_{12} B_2}{\det}, \quad C_2 = \frac{M_{11} B_2 - B_1 M_{21}}{\det}$$

---

### 6. Линейная интерполяция 
После нахождения всех узловых значений $\{y_i\}$ нам нужно узнать значение в точке $x^*$, не обязательно попадающей в узел сетки (например, $x^* = 1$ или $x^* = 2$).

1. Находим номер интервала, в который попала точка $x^*$:
   $$\text{idx} = \left\lfloor \frac{x^* - a}{d} \right\rfloor$$
   Тогда $x_{\text{idx}} \le x^* \le x_{\text{idx}+1}$.
2. На доске (фото 1, правый нижний угол) записана точная формула:
   $$y(x) = y(x_i) \cdot \frac{x_{i+1} - x}{d} + y(x_{i+1}) \cdot \frac{x - x_i}{d}$$
